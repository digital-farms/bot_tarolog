# Таро-бот — Telegram AI Tarot Bot

## Общее описание

Telegram-бот для персональных раскладов Таро с AI-трактовкой. Колода — Райдер-Уэйт (78 карт). Бот задаёт вопрос, пользователь выбирает расклад, карты «вытягиваются» рандомно, изображения отправляются в чат, а LLM (GPT-4o-mini через OpenRouter) генерирует уникальную трактовку в мистическом стиле. Монетизация — через Telegram Stars.

**Целевая аудитория:** русскоязычные и украиноязычные пользователи (18–45, преимущественно женщины), интересующиеся эзотерикой, саморефлексией, Таро.

**Позиционирование:** Таро — зеркало для саморефлексии, а не предсказание судьбы. Дисклеймер отправляется после каждого расклада.

## Функциональность

### 1. Расклады Таро

Три типа раскладов:

| Расклад | Карт | Цена | Позиции |
|---------|------|------|---------|
| **Шёпот карты** | 1 | ⭐1 | Суть / Совет |
| **Треугольник судьбы** | 3 | ⭐2 | Прошлое → Настоящее → Будущее |
| **Зеркало глубин** | 5 | ⭐3 | Ситуация → Препятствие → Подсознание → Совет → Итог |

**Флоу расклада:**
1. Пользователь задаёт вопрос текстом
2. Бот просит подтвердить вопрос
3. Пользователь выбирает расклад
4. Оплата через Telegram Stars (или бесплатно, если есть бесплатные расклады)
5. Карты «вытягиваются» рандомно (с учётом прямая/перевёрнутая, 50/50)
6. Отправляются фото карт
7. LLM генерирует персональную трактовку (~900–1500 символов)
8. Дисклеймер автоматически добавляется

**3 бесплатных расклада** «Шёпот карты» даются при регистрации.

### 2. AI-трактовка (LLM промпт)

Промпт включает продвинутые правила, разработанные по результатам ресёрча:
- **Позиция определяет контекст** — одна карта в разных позициях трактуется по-разному
- **Перевёрнутые карты ≠ противоположность** — это заблокированная/внутренняя/избыточная энергия
- **Старшие Арканы** = судьбоносное; **Младшие** = повседневное; масти определяют сферу
- **Нарратив, а не список** — карты связываются в единую историю
- **Конкретность** — трактовка привязана к вопросу пользователя
- **Тенденции, не предсказания** — «карты указывают на…», а не «тебя ждёт…»

LLM также получает: тип аркана, масть, сводку по раскладу (сколько Старших/Младших, доминирующая масть).

### 3. Уточняющая карта

После расклада можно вытянуть до 2 уточняющих карт (⭐1 каждая):
- **1 карта в раскладе** → уточняющая вытягивается сразу
- **3+ карт** → пользователь выбирает позицию, к которой хочет уточнение
- Новая карта не дублирует уже выпавшие
- LLM генерирует короткую трактовку уточнения в контексте основной карты

### 4. Озвучка расклада

- **Цена:** ⭐1
- **Технология:** OpenAI TTS (tts-1-hd, голос "nova")
- Отправляется как голосовое сообщение Telegram
- При ошибке (заблокированы голосовые) — автоматический рефанд Stars

### 5. Карта дня

- Ежедневная рассылка в 09:30 (Europe/Kyiv) подписчикам
- Отправляется фото рубашки карты с кнопкой «Раскрыть — ⭐1»
- После оплаты — фото карты, значение, и автоматический переход в мини-расклад «Шёпот карты»
- Команда: `/daily`

### 6. Профиль пользователя

- Команда: `/profile` или кнопка «👤 Профиль» (persistent keyboard)
- Показывает: имя, уровень + прогресс-бар, раскладов, звёзд потрачено, бесплатных осталось, дата регистрации, приведено друзей
- Кнопки: Начать расклад, История, Пригласить друга, Сменить язык

### 7. Система уровней

| Уровень | Emoji | Раскладов | Бонус при повышении |
|---------|-------|-----------|-------------------|
| Неофит | 🌑 | 0 | — |
| Искатель | 🌘 | 5 | +1 бесплатный расклад |
| Адепт | 🌗 | 15 | +2 |
| Мистик | 🌖 | 35 | +3 |
| Мастер | 🌕 | 75 | +4 |
| Оракул | ✨ | 200 | +5 |

Прогресс-бар отображается в профиле. При повышении — поздравительное сообщение.

### 8. Реферальная система

- Каждый пользователь может сгенерировать реф-ссылку из профиля
- Формат: `https://t.me/BotUsername?start=ref_<tg_id>`
- **Бонус рефереру (+1 бесплатный расклад)** начисляется ТОЛЬКО когда приглашённый совершает первый реальный платёж (защита от накрутки)
- Реферер получает уведомление
- В профиле: счётчик приведённых друзей

### 9. Мультиязычность (i18n)

- **3 языка:** русский 🇷🇺, украинский 🇺🇦, английский 🇬🇧
- Язык выбирается при `/start` (авто-определение + кнопки)
- Смена языка из профиля
- Все строки, кнопки, промпты LLM, сообщения об ошибках — локализованы
- Данные карт и раскладов — тоже локализованы (имена, позиции, описания)

### 10. Модуль безопасности

- **Кризисные вопросы** (суицид, самоповреждение) → расклад блокируется, отправляются телефоны доверия (RU, UA, BY, KZ, UK, USA)
- **Чувствительные темы** (медицина, юрист, финансы) → LLM получает инструкцию давать нейтральную трактовку + рекомендацию обратиться к специалисту
- Дисклеймер после каждого расклада

### 11. Админ-панель

- Встроенный Express-сервер на отдельном порту
- Аутентификация по ключу (cookie-based session)
- Функции: статистика пользователей, управление подписками, просмотр данных

## Пользовательский флоу (основной)

```
/start
  → Выбор языка (RU/UK/EN)
  → Приветственное сообщение + persistent кнопка «Профиль»
  → Кнопка «Начать расклад»
    → Ввод вопроса
    → Подтверждение вопроса
    → Выбор расклада (Шёпот / Треугольник / Зеркало)
    → Оплата Stars (или бесплатно)
    → Фото карт + AI-трактовка + дисклеймер
    → Кнопки: Озвучить | Уточняющая карта | Новый расклад | Сменить расклад | Изменить вопрос
```

## Данные карт

- **78 карт** Таро Райдер-Уэйт (22 Старших + 56 Младших Арканов)

- 4 масти Младших Арканов: Жезлы, Кубки, Мечи, Пентакли
